# The Wage Dividend of Pacification: Violence Trajectories and Neighborhood Wages in Medellín, 2006–2018

Replication package for:

> Astorquiza Bustos, B. A., & López Estrada, S. (2026). *The Wage Dividend of Pacification: Violence Trajectories and Neighborhood Wages in Medellín, 2006–2018*. Manuscript submitted to *Lecturas de Economía*.

## Overview

The paper estimates conditional wage premiums for 186 Medellín neighborhoods (2006–2018) with an augmented Mincer equation and empirical-Bayes shrinkage, and relates them to historical and current homicide trajectories in a two-way fixed-effects Spatial Durbin panel. This repository contains the code and the processed neighborhood-level data needed to reproduce all tables and figures.

## Repository structure

```
code/              R scripts, run in numerical order (or run 00_master.R)
data/raw/          Not distributed — see data/raw/README.md for access instructions
data/processed/    Neighborhood-year panel used in the second stage (+ codebook)
output/tables/     Tables generated by the code
output/figures/    Figures generated by the code
```

## Data sources and availability

| Data | Source | Availability |
|---|---|---|
| Encuesta de Calidad de Vida (ECV), 2004–2018 | Alcaldía de Medellín | Individual microdata not redistributed; available from the Alcaldía de Medellín (see `data/raw/README.md`) |
| Homicide records | SISC (Medellín) and INML | Aggregated neighborhood-year rates included in `data/processed/` |
| Financial establishments | Cámara de Comercio de Medellín | Aggregated values included |
| Metro and Metrocable stations | Metro de Medellín (GIS) | Distances included |
| Neighborhood boundaries | Alcaldía de Medellín (open data) | Included as spatial weights |

The processed panel (`data/processed/panel_186_2006_2018.csv`) allows the second-stage results (spatial analysis and Spatial Durbin models) to be reproduced without access to the raw microdata. Reproducing the first stage (Mincer equation and empirical-Bayes estimates) requires the ECV microdata.

## Software requirements

- R (version 4.3 or later)
- Packages: `data.table`, `fixest`, `sf`, `spdep`, `splm`, `spatialreg`, `ggplot2`

Install them with:

```r
install.packages(c("data.table", "fixest", "sf", "spdep", "splm", "spatialreg", "ggplot2"))
```

## Replication instructions

1. Clone or download this repository.
2. (Optional, first stage) Place the ECV microdata in `data/raw/` following `data/raw/README.md`.
3. Open R in the repository root and run `source("code/00_master.R")`.

| Script | Produces |
|---|---|
| `01_ecv_mincer_eb.R` | Harmonized ECV, Mincer equation, empirical-Bayes wage component (eqs. 1–6) |
| `02_violence_measures.R` | Historical and current violence, HPLC, HPHC, PVI (eqs. 7–12); Table 1 |
| `03_esda.R` | Moran's I statistics (Table 2); Figure 1 |
| `04_sdm_models.R` | Spatial Durbin estimates and impacts (Tables 3 and 4) |
| `05_spatial_architectures.R` | SAR, SEM, SLX, SDM, SDEM comparison (Table 5) |
